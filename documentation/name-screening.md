# Family naming review

The owner selected the exact app-menu family **RUH**. Public screening on 6 September 2026 found no exact font match in Fontdata, no exact RUH family in the Google Fonts catalog, and no matching public google/fonts issue in the bounded searches. Similar/partial matches were shown, including Frank Ruhl Libre. These are database observations, not trademark clearance.

- https://namecheck.fontdata.com/?q=RUH
- https://fonts.google.com/?query=RUH
- https://github.com/google/fonts/issues?q=is%3Aissue%20RUH

Google Fonts normally prohibits all-capitals names and abbreviations. The full FontBakery profile returned one failure, `googlefonts/family_name_compliance`, code `abbreviation`, for RUH. The font retains the owner-selected name. A naming exception must be discussed and approved for Google Fonts onboarding; no exception has been granted.

Official requirement: https://googlefonts.github.io/gf-guide/requirements.html#font-name
